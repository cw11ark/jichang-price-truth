- 所有在线页面均在 2026-10-29 04:47 CST 经 cw11ark 对应的香港出口重新抓取；不是沿用 10-25 摘要。
- 第三方原文同时保留 HTML 与抽取文本快照；`capture-meta.json` 记录最终 URL、HTTP 状态、字节数与 SHA-256。

- 自动门禁只验证在线来源仍可访问并包含区分度足够的 token；复杂结论仍由上面的逐项字段对照得出。

## 给读者的核价方法

1. 先看测评页发布日期和最近更新时间；‘有更新文字’不等于价格表也已更新。
2. 从永久官网进入并登录，确认账号实际可见的套餐组；不要只看 guest 接口的全量响应。
3. 同时核对流量档、付款周期和总价。‘折合月价’不等于可以月付。
4. 付款前重新截图或记录套餐名与总价；价格改变时保留时点，不把历史差异写成永久结论。
